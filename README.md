# Kaysin v2

Source-identity-led Next.js artist-site direction. This is separate from the approved `../kaysin` v1 and independent `../kaysin-v3` proposal.

## Preview

- Local production: http://127.0.0.1:4197
- Temporary review link: https://because-alphabetical-bath-launch.trycloudflare.com
- Palette: `/research/original-palette.png`

```sh
npm install
npm run build
npm run start
```

`npm run dev` uses the same port. Do not run a production build underneath a server using the same `.next` directory. Stop only this project's exact process before rebuilding.

## Direction

Actual Squarespace midnight/deep-blue surfaces, white original wordmark, ice music surface and periwinkle functional controls. Local original Istok Web faces, licensed under OFL. Real original-site and public-Instagram photography, current artwork-led music, six genuine preview streams, an opt-in Day Trip video and real booking/management paths. No generated likenesses, fake gigs, telemetry decoration or invented form backend.

The top-left Instagram link avoids printing the same wordmark twice immediately above the hero. Mobile uses a behind-the-booth photograph rather than forcing a landscape crowd image into a narrow crop. Circle-menu behavior is copied into this isolated project, not changed in v1. One audio element serves all release controls; audio/video starts stop competing media.

## Motion

GSAP drives the same trigger-origin circular mobile dialog and reverse close. Lenis handles desktop wheel scrolling only, keeps native touch scrolling, respects reduced motion, and resumes anchor movement after the menu closes.

## Launch boundaries

The temporary link is accessible to anyone holding it while the tunnel is running; it is not a deployment to the artist's domain. Indexing is disabled. Public photography/artwork remain subject to rights clearance; some Instagram images are source thumbnails and need approved high-resolution replacements for a large public launch. Third-party audio/video availability is not controlled by this project. No upcoming-date inventory is asserted.
